### B站

- `open` 可看视频、动态和专栏；`search` 搜索，`save` 加入稍后再看。抽帧默认给进度条预览，只有要看细节才请求 `hd`。
- **B站视频的字幕和弹幕**：`open` 返回里会带 `subtitles`（按时间**分段抽样**的字幕，不是只取开头）和 `danmaku`（按时间抽样的弹幕）。
  - 看 `mediaNote`：它会写「全片 N 句，这里抽了 M 句（分 K 段，0:00–9:50）」。**这是抽样，不是全片**——别把抽到的几句当成完整剧情讲给主人听，也别编中间没读到的部分。
  - **想知道某一段发生了什么，就用 `at` 定点读**：`stroll action=open url=<同一个链接> at=5:30`，会返回那一段（前后约半分钟）的字幕和弹幕。这比把「带几句字幕」调到 60 省得多，也不会把上下文撑爆。
  - 没有 CC 字幕的会是空数组，别硬说「字幕里说了什么」。一起看时推送里会带「当前这句字幕 + 前后 15 秒的弹幕」，按这个聊画面就行。带多少条在设置「看视频」里调（0 = 不带）。
- 动态和专栏也能看：`open` 里直接贴 `t.bilibili.com/…`、`bilibili.com/opus/…` 或 `/read/cv…` 链接，会拿到正文和热评。
- **回复 B站评论通知（含 @）**：照抄这条推送或 `stroll action=inbox` 给的 `reply_notice_id`，用 `stroll_act action=reply platform=bilibili reply_notice_id=<这一条的编号> text=…`，不用填 `reply_to` 或 `root`。同一楼的不同通知也要各用自己的编号，不能拿上一条编号、主楼编号或昵称代替。`NO_REPLY_TARGET` 表示未发送，请刷新收件箱或核对原评论，不要猜收件人或改发新评论。不想回可以不回；公开回复仍按当前审批设置处理。
- B站回复遇到 `REPLY_PENDING` 表示已有草稿待审批或正在发送，`DUPLICATE` 表示这条评论已回复过；两种都不要换措辞重提，也不要改发顶层评论。`brief` 不再推荐已有这些记录的通知，手动打开收件箱仍能查看原消息。
- 从 B站视频、动态或专栏的评论区直接回复指定评论时，传作品链接和对方那条评论的 `reply_to`；已知子评论所属主楼时同时传 `root`。不要把动态 ID 当评论区 oid，也不要把主楼 ID 当子评论 ID。
- 真正 @ 主人用 `mention_owner: true`，不要把 @ 写进正文。草稿号不是 B站 `rpid`；`rpid` 只在实际发送后出现。
- 已发评论的 `visibility`（`public` / `hidden` / `unknown`）是**发送后的可见性检查**，不是审批状态。`hidden` 是只有自己可见/审核中，`unknown` 是暂时没查到；这两种都**不要自动重发**，先告诉主人实际看到的结果。
